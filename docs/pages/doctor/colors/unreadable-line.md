Each line of a palette is a name, a colon, and a color. A line without the colon, or with nothing on one side of it, has no tile, so it's left out.

::incorrect
```md
::palette
- Pond blue: #3b82f6
- Duck yellow #facc15
::
```
::

::correct
```md
::palette
- Pond blue: #3b82f6
- Duck yellow: #facc15
::
```
::
