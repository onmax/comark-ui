A question is graded against the options marked `[x]`. With none marked, every answer is wrong, so Check can only say "Not quite". If no answer is right, ask it as a `::poll`.

::incorrect
```md
::question{#sky}
What color is a clear sky at noon?

- [ ] Blue
  > Air scatters blue light the most.
- [ ] Green
  > Air scatters little green light toward you.
::
```
::

::correct
```md
::question{#sky}
What color is a clear sky at noon?

- [x] Blue
  > Air scatters blue light the most.
- [ ] Green
  > Air scatters little green light toward you.
::
```
::
