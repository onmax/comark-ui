A reader who picks a wrong option sees its `>` reason, which is the lesson for them. Without one, they learn only that they were wrong. Say what the option gets wrong.

::incorrect
```md
::question{#falsy}
Which value is falsy?

- [x] `0`
- [ ] `[]`
::
```
::

::correct
```md
::question{#falsy}
Which value is falsy?

- [x] `0`
- [ ] `[]`
  > Every object is truthy, empty arrays too.
::
```
::
