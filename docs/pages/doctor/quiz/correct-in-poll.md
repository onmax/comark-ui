A poll counts votes and has no right answer, so it ignores `[x]`. Leave every option as `- [ ]`, or make it a `::question` if one answer is right.

::incorrect
```md
::poll{#next-lesson}
What should the next lesson cover?

- [x] Web Workers
- [ ] Streams
::
```
::

::correct
```md
::poll{#next-lesson}
What should the next lesson cover?

- [ ] Web Workers
- [ ] Streams
::
```
::
