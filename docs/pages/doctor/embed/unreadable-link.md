A link to a provider with a player, such as YouTube or Vimeo, that the player's ID can't be read from. It renders as a link card instead, and the message says which links the provider's player reads.

::incorrect
```md
::embed{url="https://vimeo.com/staff" title="Vimeo staff picks"}
::
```
::

::correct
```md
::embed{url="https://vimeo.com/76979871" title="The new Vimeo player"}
::
```
::
